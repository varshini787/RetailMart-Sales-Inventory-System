# RetailMart Sales & Inventory Management System

A web-based retail management system for managing products, customers, inventory, orders, and sales reports.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL

## Features

- Dashboard with sales statistics
- Product management
- Customer management
- Inventory tracking
- Order management
- Sales reports
- MySQL database integration
- REST-style backend APIs

## Database Concepts

- SQL Queries
- Views
- Stored Procedures
- Triggers
- Relational Database Design
